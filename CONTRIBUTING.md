# Contributing to Nous

Thanks for wanting to help build this. Nous is one project by one person right now, but the door is open.

---

## The one hard rule

**Every contribution must run fully locally.**

No PR that introduces a cloud dependency, external API call, telemetry, or centralised data collection will be merged. Ever. This is non-negotiable — it is the entire point of the project.

---

## Before you open a PR

1. Open an issue first and describe what you want to build or fix
2. Wait for a response before writing code — avoids wasted effort if it conflicts with the roadmap
3. Keep PRs focused on one thing

---

## What's welcome right now

- Bug fixes
- Documentation improvements
- Hardware compatibility testing and reports
- Docker / setup script improvements
- Home Assistant integration work
- Performance improvements to the inference stack

## What's not ready yet

- Flutter app contributions (architecture not finalised)
- SvelteKit dashboard contributions (not started)
- New AI model integrations (stack is still stabilising)

---

## Code style

- Keep it readable over clever
- Comment anything non-obvious
- No external dependencies without discussion first
